📷 Enable Camera Access

Browsers block camera on file://. Run a local server instead — pick any option:

OPTION 1 — Python (easiest)
python -m http.server 8080
Then open: http://localhost:8080/attendance.html
OPTION 2 — Node.js / npx
npx serve .
Then open the URL it shows.
OPTION 3 — VS Code
Install the Live Server extension → right-click attendance.html → Open with Live Server
💡 Tip: Double-click start-server.bat in the same folder — it opens everything automatically!
